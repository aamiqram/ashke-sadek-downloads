## Install (Android)

1. Open the downloaded `Ashke-Shadek.apk` from Chrome → Downloads.
2. If asked, allow installs for the browser: Settings → Apps → Special access → Install unknown apps → Chrome → Allow.
3. If Google Play Protect shows a warning, tap **More details → Install anyway**.
4. On MIUI (Redmi/POCO), also allow Chrome under Settings → Privacy protection → Special permissions.

The app updates itself from this repository's releases. The application source code is private; this repository only hosts public APK builds.
